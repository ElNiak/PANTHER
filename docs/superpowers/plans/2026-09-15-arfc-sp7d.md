# SP7d — instrument and runs: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the draft-quality instrument end to end — lint and build metrics in
`ai-rfc experiment analyze`, a blinded quote-verified `ai-rfc experiment judge`, and an anchored
`ai-rfc experiment ground-truth` with its aioquic dataset — and stop at the threshold of spending.

**Architecture:** Three buildable parts over one shared escaping fix. Lint is a pure function, so
`analyze` re-runs it per revision against each revision's *frozen* checkpoint manifest; build is
expensive, so it runs once at the final tag and only when the campaign carries a toolchain. The
judge reuses the codebase's existing hardened `ClaudeCliCall` transport rather than building a
second one, gaining an init-event surface assertion and cost capture *inside* it. Ground-truth is a
deterministic anchored-fact matcher that needs no model at all. Every part is exercised against
`fake_claude` and fixtures at zero cost.

**Tech Stack:** Python 3.10 (`.venv`), pytest, argparse, PyYAML, `claude -p` via subprocess
(Phase 5 only). Python 3.11 (`~/ai-rfc-experiments/venv-optimize`) for the gepa-importing selection.

**Spec:** `docs/superpowers/specs/2026-09-02-arfc-draft-quality-design.md` — the SP7d roadmap row
(§Roadmap placement) and §"Settled by the judge probe (2026-09-03, `claude` 2.1.259)".

**Context — why this row exists.** Every draft the loop has produced has zero figures, zero tables
and no state machines, and the instrument had no quality dimension at all (`experiment/metrics.py`).
SP7a–SP7c built the *producers* — `draft lint`, `draft build`, structures, consolidation rounds.
SP7d builds the *instrument* that measures them, so the improvement those rows made is measured
rather than asserted. It is the last row before money is spent, and the three evaluation runs it
prepares for are explicitly **not** performed here.

## Global Constraints

Copied verbatim from the spec, the project's rules and the row brief. Every task's requirements
implicitly include this section.

- **Never use an Anthropic API key.** The judge runs on the interactive OAuth profile. This makes
  the blinding leak **permanent, not provisional** — see D-1 below.
- **Nothing in Tasks 1–11 spends.** If a step appears to require a paid model call, stop and say so.
- **Never re-run `audit` or `analyze` against existing pilot data.** `docs/experiments/`,
  `tests/driver/fixtures/`, `~/ai-rfc-experiments/` and `~/arfc-experiments/` are read-only
  evidence: copy out, never in. A recording edited to match later code is no longer evidence.
  Precisely: **never edit an existing recording.** Adding a *new* dated file under
  `docs/experiments/` is the established precedent (`2026-09-03-sp7a-mark-baseline.md`) and is what
  Task 11 Step 3 does.
- **Style:** Google-style docstrings (Args/Returns/Raises) on public functions; line length 88;
  `from __future__ import annotations` where neighbouring modules use it; comments only where the
  *why* is not obvious; **no backward-compatibility shims**; fixed dates in every fixture; no test
  needle that matches a fixture's own name.
- **Commits:** `type: lowercase summary` in ai_rfc, `type(scope): lowercase summary` in PANTHER.
  Blank line then `Claude-Session: <session URL>` as a second `-m`. Use `-F <file>` for any message
  containing backticks — zsh command substitution ate two verb names on the previous row.
  Never `--no-verify`, never `git add -A` / `git add .`; stage by explicit path and run
  `git status --short` in every repository touched before every commit.
- **Test invocation:** sandbox OFF for pytest/pip/nested git; prefix with `SSLKEYLOGFILE=`; pass
  `-p no:cacheprovider`; always `--basetemp` under `/tmp/claude-501`. When `TMPDIR` is unwritable
  `tempfile` falls back to the CWD, pytest writes inside the repo, and every git-shelling fixture
  fails with exit 128 — that symptom is a temp-directory problem, not a broken suite.
  The full suite takes ~4m40s, longer than a default command budget.
- **Source hygiene:** `tests/substrate/test_source_hygiene.py` forbids non-printable codepoints.
  The editing tool normalises `\uXXXX` escapes into raw characters — **build any such escape by
  concatenation** or you will silently commit the character.
- **The SDD ledger is gitignored**; a `git clean -fdx` destroys it.

### Rulings I made (R-numbers), each with its cost if wrong

- **R1 — Reuse `ClaudeCliCall`; do NOT reuse `build_judge`.** `optimize/judge.py`'s `build_judge`,
  `RUBRIC`, `_prompt`, `_cache_key` and `_parse` are welded to the optimize scoring loop: the
  signature is `list[ClaimHunk] -> list[Judgement]`, the rubric is claim-vs-diff prose, and
  `_parse` hard-rejects anything outside `_PERMITTED_SCORES = (0.0, 0.5, 1.0)`
  (`optimize/judge.py:36`). A draft-quality judge has a different unit, rubric and score domain;
  extending it would mean gutting it. `ClaudeCliCall` *is* the general `str -> str` transport and is
  already model-agnostic, profile-based (no API key) and hardened.
  *Cost if wrong:* a second transport to maintain, and the optimize loop's hardening drifts from the
  judge's. **This ruling satisfies SEARCH-BEFORE-CREATING; the greps that proved it are in D-7.**
- **R2 — The init assertion and cost capture go INSIDE `ClaudeCliCall`, not around it.**
  `__call__` today parses the stream then reads only `result_event`
  (`claude_cli.py:236-258`); `init_event` is never called and `total_cost_usd` is discarded.
  Both gaps are in the transport, so both fixes belong there. The optimize loop gains the same
  hardening for free. *Cost if wrong:* a change to a module the 3.11 optimize selection covers —
  mitigated by re-running that selection (Task 11).
- **R3 — Lint per revision uses the FROZEN checkpoint manifest, never the live `manifest.yaml`.**
  `lint()` is manifest-relative in two places: `_structures` (`draft/lint.py:399`) diffs rendered
  structures against the draft's blocks, and `_citations` (`:331`) computes `uncited` and
  `cited_fraction` against `manifest.claims`. Linting `draft-…-01` against the final-state manifest
  would report every later structure as `unrendered` and every later claim as `uncited`.
  *Cost if wrong:* every early revision scores catastrophically and the trend is pure artifact.
- **R4 — Build runs once at the final tag, not per revision.** `build()` rmtree's and re-clones a
  scratch repo per call (`draft/build.py:373-389`) and needs a provisioned toolchain. 37 revisions ×
  a full `txt html lint idnits` cycle is not an analysis step. The precedent is
  `optimize/evaluator.py:171-177`, which already builds `_latest_tag(workspace)` only.
  *Cost if wrong:* no per-revision build trend; the final-tag build still gates.
- **R5 — Analysis writes BESIDE the workspace, never inside it.** Both existing precedents agree:
  `metrics.run_gates` copies into a `TemporaryDirectory` and documents the workspace is "never
  written to"; `optimize/evaluator.draft_build_report` writes to `workspace.parent / "draft-build"`.
  *Cost if wrong:* `analyze` mutates evidence, which the row's own constraints forbid.
- **R6 — New logic lives in `ai_rfc/experiment/judge.py` and `ai_rfc/experiment/ground_truth.py`.**
  **Never** `experiment/<name>/cli.py`: `tests/substrate/test_cli_conventions.py:148-178` rglobs
  `**/cli.py` and asserts set-equality against `ENTRY_POINTS`, so such a file fails the suite unless
  it is also registered as a root verb — which it must not be.
  *Cost if wrong:* a red suite that looks like a packaging bug.
- **R7 — `experiment` verbs get NO `docs/parity.md` row.** `tests/server/test_parity.py:168` selects
  rows by `line.startswith("| \`ai_rfc_")` and `:229` asserts
  `set(names) == {tool.__name__ for tool in tools.ALL_TOOLS}`. A row for `experiment judge` either
  is invisible or breaks that equality. Parity covers the agent tool surface; `experiment` is the
  harness that runs the arms, not a surface any arm types.
  *Cost if wrong:* a red parity suite. **Note:** the surface is **20 tools today, not 16** —
  `docs/experiment-protocol.md:123`. The brief's "16 MCP tools" is stale; do not repeat it.
- **R8 — Editing `tests/experiment/fake_claude/claude-lm` is permitted.** It is a stand-in binary,
  not a recording. The fixtures rule protects `tests/driver/fixtures/` and `docs/experiments/`;
  `fake_claude/` is neither. *Cost if wrong:* none — it is test-only and never used outside tests.

### D-numbered deviations (opened in Phase 2, before any task ran)

- **D-1 — The spec's "until an API key is provisioned" framing is corrected.** The spec says the
  blinding leak persists until an API key is provisioned and that switching to `--bare` would then
  be a one-line change. **This project never uses an Anthropic API key**, so the accepted leak is
  **permanent**. Corroborated independently: `--bare`'s help text says auth is strictly
  `ANTHROPIC_API_KEY` or `apiKeyHelper` — keychain and OAuth are never read. The manifest field must
  say "permanent under OAuth", not imply a pending upgrade.
- **D-2 — The before/after table carries a content caveat, measured.** The MARK A1 draft is
  **166,554 bytes / 2,911 lines**; the six pilot drafts are **9,028–18,450 bytes**. That is a
  10–18× size gap across different corpora. Both sides are linted by the *final* instrument, so
  instrument drift is excluded; content drift is not, and the artifact must say so in prose.
- **D-3 — The `run()` dispatch chain has NO `else`.** `ai_rfc/experiment/cli.py:1287-1556` is an
  `if/elif` chain that falls through to `return 0` at `:1556`. A verb added to `configure()` but
  never given an `elif` **exits success having done nothing**, and nothing in the suite catches it.
  Task 4's and Task 7's first RED is exactly this, asserted per verb.
- **D-4 — `claude-lm` cannot exercise an init assertion today.** `tests/experiment/fake_claude/claude-lm:28`
  emits `{"type": "system", "subtype": "init", "model": "fake-lm", "tools": []}` — `tools` is
  **hardcoded**, not derived from argv, and `mcp_servers` is **absent entirely**. An assertion
  written `init.get("mcp_servers") or []` passes **vacuously**, proving nothing. Task 5 ports the
  argv-derived preamble from the sibling agent fake (`fake_claude/claude:642-653`, which already
  emits `tools`, `mcp_servers`, `slash_commands`, `apiKeySource`) before any judge RED is written.
- **D-5 — `claude-lm` has no reply mode for the judge's schema.** Its only text modes are `fenced`
  (wraps `proposal` in a fence) and `verdict` (the fixed `{"score","rationale"}` object,
  `claude-lm:80-83`). Task 5 adds a `raw` mode.
- **D-6 — `--effort low` is mandatory and `--model` must be pinned.** Measured (CLI 2.1.260): a
  sonnet routing call at default effort took **112 s**; at `--effort low`, 3–4 s. Omitting `--model`
  resolves to `claude-opus-5[1m]`, not a cheap default. `JUDGE_EFFORT = "low"` already exists at
  `experiment/cli.py:74`.
- **D-7 — Quote verification and the two-`LintReport` comparison are net-new.** Greps that prove it:
  `quote` across `ai_rfc/**/*.py` returns only YAML/shell quoting and an interview answer field;
  `before.*after|compare|comparison|delta|diff_table` returns only `config.py:821` (config dicts),
  `experiment/summary.py:136 citation_delta` (manifest/citation, not lint) and
  `views/emit.py:331` (digests). Nothing takes two `LintReport`s.
- **D-8 — Packaging: the dataset needs BOTH an `__init__.py` and a `package-data` entry.**
  `pyproject.toml:36-37` uses `[tool.setuptools.packages.find]`, **not** `find_namespace`, so a
  directory without `__init__.py` is absent from the wheel with no source-tree test noticing;
  `[tool.setuptools.package-data]` (`:38-40`) lists only `ai_rfc.driver` and `ai_rfc.lifecycle`.
  Load the dataset via `importlib.resources`, never a path relative to `__file__`.
- **D-9 — Every new argument must carry `help=`.** `tests/agent/test_verbs.py:250-284` recurses
  `argparse._SubParsersAction.choices` at every depth from `cli.build_parser()` and asserts the
  undocumented list is empty (currently 0). This holds new verbs automatically.
- **D-10 — The `--output-format json` envelope is version-dependent; `stream-json` is the safe
  choice.** Measured: CLI ~2.1.260 returned a JSON *list* including `rate_limit_event`; 2.1.268
  returned a bare *object* with no rate-limit event at all. The judge uses `stream-json` (as both
  the spec and `ClaudeCliCall` already do) and must take the last `type == "result"` element.

```python
def _code(value: Any) -> str:
    """One value as a Markdown code span that its own content cannot break.

    A run of backticks inside the value is fenced by a longer run outside it,
    per CommonMark; a leading or trailing backtick needs the padding space.

    Args:
        value: Any value; ``None`` renders as the em dash, never as a span.

    Returns:
        The fenced span, or ``"—"`` for ``None``.
    """
    if value is None:
        return "—"
    text = str(value).replace("\n", " ")
    longest = max((len(m) for m in re.findall(r"`+", text)), default=0)
    fence = "`" * (longest + 1)
    pad = " " if text.startswith("`") or text.endswith("`") else ""
    return f"{fence}{pad}{text}{pad}{fence}"


def _cell(value: Any) -> str:
    """One value as a table cell that cannot add a column or a row.

    A GFM table row is exactly one line, and CommonMark treats CR, LF and CRLF
    alike as line endings — so neutralising only ``\\n`` leaves ``\\r`` splitting
    the row identically. ``printable`` is the predicate over the whole category
    rather than a list of characters somebody thought of; it runs first, so a
    line ending is already a visible escape by the time pipes are doubled.

    Args:
        value: Any value.

    Returns:
        The cell text, printable-escaped with pipes escaped.
    """
    return printable(str(_fmt(value))).replace("\\", "\\\\").replace("|", "\\|")
```

**`printable` is `ai_rfc.driver.printable` (`ai_rfc/driver/__init__.py:27`) — import it, do not
write one.** `ai_rfc/experiment/config.py:23` already imports from that package root, so this adds
no dependency edge, and the module imports nothing itself. Its docstring records why the category
predicate beats an enumeration here: `driver/stop.py`'s `_quoted` shipped `shlex.quote` first and
then C0+DEL, and **both were necessary and insufficient**. `_code` composes it the same way.

Then route: the five spans at `:112-117` through `_code`; every `{run_id}`, `{arm}`,
`{cluster_id}` and `_fmt(...)` cell in `_arm_rows`, `_run_rows` and `_cluster_rows` through `_cell`.
