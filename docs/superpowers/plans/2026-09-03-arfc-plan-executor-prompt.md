On risk: you decide, without asking, everything inside a task's file list — reads, edits, test runs, lint, plan-file corrections found in review, and commits once the status check is clean. You ask first, and stop until answered, before any `git push`, before bumping the PANTHER submodule pointer, before any command that spends money (`claude -p`, `campaign init`, `experiment run`, `ai-rfc run` with sessions configured, judging), before deleting or moving any workspace, campaign, baseline or run directory, before editing a file outside the plan's File Structure, before re-provisioning the toolchain, and before changing anything a spec decided. Where the plan is ambiguous, the spec wins on decisions and the code wins on facts, and you state the interpretation you chose in the deviation log.
