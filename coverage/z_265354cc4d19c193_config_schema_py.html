9class MemcheckConfig(ExecutionEnvironmentPluginConfig): 

10 """Valgrind Memcheck configuration for memory error detection. 

11 

12 Memcheck detects memory management errors in C/C++ programs: uninitialized 

13 reads, use-after-free, memory leaks, invalid heap operations, and mismatched 

14 allocation/deallocation calls. Use when debugging native services (e.g., 

15 Picoquic, LSQUIC) for memory safety issues. 

16 

17 Related execution environments: 

18 - Helgrind: Thread safety and data race detection (also Valgrind-based). 

19 - GPerf Heap: Heap profiling for allocation patterns and memory usage 

20 (lighter weight, no error detection). 

21 - GDB: Crash debugging with stack traces (complementary to Memcheck). 

22 

23 Inherited fields from ``ExecutionEnvironmentPluginConfig``: 

24 - ``enabled``: Whether the plugin is enabled (default: True). 

25 - ``collect_metrics``: Whether to collect metrics (default: True). 

26 

27 Example YAML:: 

28 

29 execution_environments: 

30 - type: memcheck 

31 leak_check: full 

32 track_origins: true 

33 show_leak_kinds: definite,possible,indirect 

34 output_format: xml 

35 suppression_file: /path/to/suppressions.supp 

36 """
