9class GperfHeapConfig(ExecutionEnvironmentPluginConfig): 

10 """Google Performance Tools (gperftools) heap profiling configuration. 

11 

12 Uses ``libtcmalloc.so`` from gperftools to profile heap memory allocation 

13 patterns: where memory is allocated, how much is in use, and where leaks 

14 occur. Use when investigating memory growth, allocation hotspots, or 

15 comparing memory usage across protocol implementations. 

16 

17 Note: This is gperftools (the Google performance library), not GNU gperf 

18 (the perfect hash function generator). 

19 

20 GPerf Heap profiles *where memory is allocated*, while GPerf CPU profiles 

21 *where CPU time is spent*. They use different libraries (``libtcmalloc`` 

22 vs. ``libprofiler``) and produce different output formats. For memory 

23 *error* detection (use-after-free, buffer overflows), use Valgrind 

24 Memcheck instead. 

25 

26 Related execution environments: 

27 - GPerf CPU: CPU time profiling (also gperftools-based). 

28 - Memcheck: Memory error detection (Valgrind, slower but finds bugs). 

29 - GDB: Crash debugging with AddressSanitizer integration. 

30 

31 Inherited fields from ``ExecutionEnvironmentPluginConfig``: 

32 - ``enabled``: Whether the plugin is enabled (default: True). 

33 - ``collect_metrics``: Whether to collect metrics (default: True). 

34 

35 Example YAML:: 

36 

37 execution_environments: 

38 - type: gperf_heap 

39 heap_profile_allocation_interval: 524288 

40 heap_check_type: normal 

41 enable_leak_check: true 

42 generate_pdf: true 

43 output_format: heap 

44 """
