$ python -m ai_rfc check --help
usage: ai-rfc check [-h] --out OUT [--repo REPO] [--strict] manifest

Report which claims in a reconstructed requirement manifest are not backed by the code their
anchors point at: check the schema, weigh every claim against the promotion rule, and optionally
verify repository anchors against their pinned commits.

positional arguments:
  manifest     Path to the YAML manifest.

options:
  -h, --help   show this help message and exit
  --out OUT    Directory for report.json, report.yaml and report.md.
  --repo REPO  Clone against which repository anchors are verified.
  --strict     Exit 3 on any finding: a claim recorded above what its evidence supports, or an
               anchor that does not resolve at its pinned commit.

$ python -m ai_rfc draft checkpoint --help
usage: ai-rfc draft checkpoint [-h] --timeline TIMELINE --cluster CLUSTER --out OUT
                               [--consolidation CONSOLIDATION] [--base BASE]
                               manifest

positional arguments:
  manifest              Manifest to freeze.

options:
  -h, --help            show this help message and exit
  --timeline TIMELINE   Timeline directory.
  --cluster CLUSTER     Cluster id the manifest state belongs to.
  --out OUT             Checkpoints root directory.
  --consolidation CONSOLIDATION
                        Write a consolidation checkpoint with this ordinal instead of a cluster
                        one.
  --base BASE           The cluster checkpoint a consolidation follows. Required with
                        --consolidation.

                         --revisions REVISIONS --out OUT [--strict]
                         [--consolidations CONSOLIDATIONS]
                         draftrepo

positional arguments:
  draftrepo             The nested draft repository.

options:
  -h, --help            show this help message and exit
  --timeline TIMELINE   Timeline directory.
  --checkpoints CHECKPOINTS
                        Checkpoints root.
  --questions QUESTIONS
                        Question register.
  --revisions REVISIONS
                        Revision map.
  --out OUT             Directory for gate-report.json.
  --strict              Exit 3 when any finding is reported.
  --consolidations CONSOLIDATIONS
                        Consolidation checkpoint root. Default: the sibling of --checkpoints.
